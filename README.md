# Raffle Management System

A digital raffle management system designed to simplify the creation, organization and management of fundraising campaigns.

## Overview

The project provides a web-based platform for managing raffle campaigns, number availability, reservations, orders and payment tracking.

## Features

- Digital raffle campaign management
- Number selection and availability tracking
- Order and reservation management
- Payment status tracking
- Administrative dashboard
- Participant order consultation
- Google Sheets integration through Google Apps Script

## Technologies

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
- GitHub Pages
